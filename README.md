# 🎬 Filmaty Bot (بوت فيلماتي)

بوت تليجرام احترافي ومحرك بحث وبث وسائط فائق السرعة، يعمل على سحابة **Cloudflare Workers**، يجمع الأفلام والمسلسلات من أقوى المواقع والسيرفرات العربية والعالمية مع الفحص المباشر والحي للروابط واقتراح أفضل وأسرع مشغل وتحميل مباشر.

---

## 🌟 المميزات الرئيسية

- 🎬 **أمر `/film <اسم الفيلم>`**:
  - يبحث عن الأفلام ويجلب جميع الأعمال ذات الصلة (مثل البحث عن `marvel` يجلب جميع أفلام مارفل).
  - اختيار العمل ⬅️ اختيار الجودة (`1080p FHD`, `720p HD`, `480p SD`, `كل السيرفرات`).
  - فحص حي للخوادم واقتراح **الخيار الأفضل والأسرع**.
  - **مشاهدة مباشرة سينمائية** داخل التليجرام عبر مشغل WebApp مدمج.
  - **تحميل مباشر فائق السرعة** مع إظهار حجم الملف بدقة.
  - سيرفرات بديلة متعددة.

- 📺 **أمر `/series <اسم المسلسل>`**:
  - بحث ذكي وتصنيف هرمي للمسلسلات:
    1. **المواسم**: تقسيم العمل لمواسم (`الموسم 1`, `الموسم 2`, ...).
    2. **الحلقات**: شبكة تفاعلية سريعة للحلقات (`حلقة 1`, `حلقة 2`, ...).
    3. **الجودات**: اختيار الجودة المناسبة (`1080p`, `720p`, `480p`).
    4. **السيرفرات والمشاهدة**: فحص وتوليد روابط التشغيل والتحميل الفورية.

- 🛡 **فحص مباشر وصارم للروابط (Live Health Probe)**:
  - يقوم البوت بعمل فحص HTTP Range & HEAD قبل إرسال الروابط لضمان عدم وجود روابط معطلة (404/Dead/403).
  - قياس زمن الاستجابة (Latency ms) وترتيب السيرفرات حسب السرعة.

- 📁 **الأرشيف الشخصي (`/archive`)**:
  - قاعدة بيانات سحابية (Cloudflare D1) لحفظ سجل مشاهداتك وأفلامك المفضلة للرجوع إليها في أي وقت.

- 🚀 **نظام العمل في الخلفية (Background Scraper & Proxy)**:
  - يعمل بدون سيرفر محلي (Serverless Worker 24/7).
  - بروكسي فيديو مدمج (`/stream`) لتخطي قيود الـ CORS و Referer ودعم التقديم والتأخير (Seeking).
  - مشغل HTML5 أنيق متكامل مع Telegram WebApp (`/watch`).

## 🏗 البنية الهندسية للمشروع

```
src/
├── index.ts               # موجه طلبات Cloudflare Worker والـ Webhook والمشغل
├── env.ts                 # ربط المتغيرات البيئية وقواعد البيانات
├── telegram/
│   ├── client.ts          # عميل Telegram Bot API
│   ├── handlers.ts        # معالج الأوامر والرسائل والأزرار التفاعلية
│   ├── keyboards.ts       # بناء القوائم والأزرار الشجرية
│   └── views.ts           # قوالب الرسائل العربية والتنسيقات
├── engine/
│   ├── normalize.ts       # معالجة النصوص العربية وحساب التشابه والمواسم
│   ├── probe.ts           # نظام فحص جودة وسرعة الروابط
│   ├── token.ts           # تشفير وفك تشفير جلسات المشاهدة الآمنة HMAC-SHA256
│   ├── store.ts           # إدارة الذاكرة المؤقتة (KV) وقاعدة بيانات الأرشيف (D1)
│   └── proxy.ts           # بروكسي بث الفيديو ودعم Byte-Range
├── providers/
│   ├── laroza.ts          # سيرفرات لاروزا (10 سيرفرات + تحميل مباشر MP4)
│   ├── faselhd.ts         # سيرفرات فاصل إعلاني
│   ├── akwam.ts           # سيرفرات أكوام
│   ├── mycima.ts          # سيرفرات وي سيما / ماي سيما
│   ├── embed.ts           # سيرفرات البث العالمية متعددة الجودات
│   └── index.ts           # المجمّع والموزع المتوازي
└── player/
    └── html.ts            # مشغل الفيديو السينمائي HTML5 + HLS.js
```

## 🔐 المتغيرات البيئية والأسرار (Cloudflare Secrets)

- `BOT_TOKEN`: توكن بوت التليجرام الخاص بك.
- `SIGNING_SECRET`: مفتاح التوقيع لتوليد روابط المشغل الآمنة.
- `WEBHOOK_SECRET`: رمز حماية الـ Webhook.
- `OWNER_IDS`: معرفات حسابات التليجرام المسموح لها بالاستخدام (اختياري).
- `PUBLIC_BASE`: الدومين العام للوركر (مثال: `https://filmaty.hudhaifa-bio.workers.dev`).
